# library-database-sql


A small library database with sample data and example queries.

## Tables
- books
- members
- loans


## Files
- schema.sql: table definitions and sample data
- queries.sql: 10 example queries using JOINs, GROUP BY, and LEFT JOIN
- extras.sql: fines table, indexes, views, and a window-function ranking query


## How to run
Run schema.sql first, then the queries in queries.sql, in SQLite or any SQL tool.
